# Hogar — Sistema de Gestión Laboral

Aplicación web moderna para administrar toda la información laboral de trabajadoras del hogar en Perú.

## Características

✅ **Registro de horas extras** con detección automática de feriados y domingos  
✅ **Calendario mensual** interactivo  
✅ **Gestión de vacaciones** con cálculo automático  
✅ **Bonos extraordinarios**  
✅ **Liquidación mensual** completa con gratificación (julio/diciembre)  
✅ **Dashboard** con métricas e indicadores  
✅ **Historial** de liquidaciones anteriores  
✅ **Reportes** compartibles  

## Uso

1. Abre la aplicación en tu navegador
2. Ingresa los datos de la trabajadora en la configuración inicial
3. Comienza a registrar horas extras, vacaciones y bonos
4. La aplicación calcula automáticamente todo según la legislación peruana

## Tecnología

- **HTML5** — Estructura
- **CSS3** — Diseño moderno (Notion/Linear inspired)
- **JavaScript ES6** — Lógica sin frameworks
- **LocalStorage** — Almacenamiento local (preparado para Firebase/Supabase)
- **Chart.js** — Gráficos
- **html2canvas** — Captura de reportes

## Instalación

No requiere instalación. Funciona directamente en el navegador.
